# S4 Loopsoar UI 风格（自有设计语言）

> 目标：以 Claude/DSH 的「克制、圆角、低饱和」为底，融入 Loopsoar 官方图标三色，
> 形成**可复用、可扩展**的自有风格。所有数值收敛在 `packages/ui/src/theme.ts` 与 `index.html` 的样式类里。

## 1. 色板（源自官方图标：深墨 / 亚麻白 / 赭石）

| 角色 | 色值 | 用途 |
|---|---|---|
| `ink` 深墨 | `#111318` | 窗口/画布背景、输入框底 |
| `inkRaised` | `#17191e` | 顶栏、标题栏、抬升面板 |
| `inkPanel` | `#15171c` | 侧栏、卡片 |
| `border` / `borderStrong` | `#262a31` / `#333842` | 分隔线、容器描边 |
| `linen` 亚麻白 | `#f4efe6` | 主文本 |
| `linenMuted` / `linenFaint` | `#a8a29a` / `#6f6a63` | 次级/说明文本、占位 |
| `ochre` 赭石 | `#c8763c` | **唯一强调色**：主按钮、激活态、流式光标、状态点 |
| `ochreHover` / `ochreSoft` | `#d98a4f` / `rgba(200,118,60,.16)` | 悬停、选中底色 |

规则：**一个强调色走到底**（不再引入蓝/紫）；危险色仅用于关闭按钮 hover 与错误提示。

## 2. 形状与节奏

- 圆角阶梯：容器 12 / 卡片 10 / 控件 7-8 / 药丸 999
- 间距阶梯：4 / 6 / 8 / 10 / 12 / 14 / 16 / 20（不出现魔法数字）
- 字号：11（说明）/ 12.5（正文）/ 13-15（标题）/ 18-32（展示）
- 层级：标题栏 36 → 顶栏 48 → 标签栏 34 → 内容 → 状态条 32（全部进 `contracts/layout.ts`）

## 3. 标志性组件

1. **Claude 式输入容器**：大圆角描边容器，textarea 无边框；底行「能力条」
   （模式 chip / 权限 chip / 模型 chip + 圆形赭石发送键）；hover 抬亮、按下回弹、聚焦容器描边。
2. **能力 chip**：药丸形、图标 + 短文案、可点击进入设置对应分区；激活态赭石描边 + soft 底。
3. **自定义标题栏**：品牌 ∞ + 名称（可拖拽/双击最大化）+ 最小化/最大化/关闭。
4. **标签栏**：紧凑标签 + 关闭 + `+`；活动标签抬升面板色 + 描边。
5. **设置面板**：左导航（图标+标题+一句说明）+ 右单页表单；分区 8 个；卡片化的列表（规则/记忆/供应商）。
6. **流式渲染**：新字符「由右到左 + 由浅到深」260ms 渐入；ochre 方块光标闪烁；行级淡入。
7. **浮层秩序**：设置/确认弹窗打开时隐藏原生浏览器视图（`browser:setOverlay`），避免被网页盖住。

## 4. 动效纪律（借鉴 slime 的踩坑）

- 时长 80–260ms；位移 ≤ 4px；不做大幅进出场动画
- `prefers-reduced-motion` 与「动效强度偏好（full/reduced/off）」双重降级：**只去位移、保留淡入**
- 内联元素的位移用 `position: relative + left`（transform 对内联元素静默失效）

## 5. 图标

- 本地图标库 → `packages/ui/public/icons/*.svg`，以 CSS `mask` + `currentColor` 渲染（自动适配主题/禁用态）
- 尺寸 10/12/14/16/17；不用 emoji、不用彩色图标
