# S0 脚手架总规格（Loopsoar 基础程序框架）

> 本规格是子代理施工的唯一依据。**禁止自行发挥、禁止越界写他人目录、禁止引入规格外的依赖。**
> 总目标：一个「灵活但非常稳固」的 monorepo 骨架——契约单源、引擎纯逻辑、壳层可替换、安全 fail-closed、守卫测试先行。所有代码必须 `pnpm typecheck` + `pnpm test` 全绿（由验证子代理 S8 统一执行）。
> 语言：全部 TypeScript（严格模式）。包管理器：pnpm（workspace）。运行平台：Windows + Node 24。

### 4.1 纯逻辑（S3）——全部函数「依赖注入」，不得 import node 内建模块（fs/path/child_process 全走 platform）

- **session.ts**：`IDENTITY_CONSTRAINT(name, role)`（只以「我是 {name}」自称、不透露底层模型）；`HONESTY_PROTOCOL` 四条（不编造事实/失败如实/声称前必须真执行/不确定就说不知道）；`ANTI_SYCOPHANCY_RULE`（不过度附和：与用户偏好/事实冲突时礼貌指出、不编造认同）；`interface SystemSegments { stable: string; volatile: string }`；`buildSystemSegments(opts): SystemSegments`（stable=身份+诚实+反迎合+角色+技能清单占位；volatile=心智/记忆/工作目录占位，调用方传入）；`assertStableUnchanged(before, after)`（字节相等断言助手）。
- **filter.ts**：`MODEL_FAMILY_RE` 表（GPT/Claude/Gemini/Qwen/DeepSeek/Kimi/GLM/llama 等家族名 + 「作为一个AI」「我是语言模型」「底层模型」），`applyOutputFilter(text)`（统一替换为「Loopsoar 平台」）、`createStreamFilter()`（增量流过滤，处理跨 chunk 边界）。
- **claims.ts**：`CLAIM_VERBS = ["已保存","已生成","已创建","已写入","已下载","已导出","保存到"]`；`auditClaims(text, exists: (p:string)=>Promise<boolean>): Promise<ClaimFinding[]>`（跳过 fenced code block、URL/域名残片；路径正则提取 60+ 扩展名白名单；每轮核验语义）。
- **router.ts**：`ModelPoolEntry { id, provider, priority, roles, cooldownUntilMs }`、`class ModelRouter`：`pick(roles, now)`（过滤 cooldown → 按 priority 降序）、`markCooldown(id, ms, now)`、`fallbackChain(roles)` 返回有序队列。
- **budget.ts**：`BudgetUsage { rounds, toolCalls, totalTokens, wallClockMs }`；`BudgetLimits`（四字段可选，硬上限取 `BUDGET_HARD` 封顶——**自定义 loop 只能收紧**）；`budgetReason(usage, limits): string|null`（命中即归因文案）；`warnThreshold(limits)`（剩 3 轮预警文案）。
- **events.ts**：`type LoopEvent = { seq:number; type:"chunk"|"reasoning"|"tool"|"progress"|"done"|"error"|"heartbeat"; data: unknown; ts: number }`；`EventSink = (e: LoopEvent) => void`。
- **steerBus.ts**：`class SteerBus`：`push(text)`（≤8 条、每条截断 2000 字）、`drain(): string[]`。
- **llm/index.ts**：`interface LlmClient { invoke(req: LlmRequest): AsyncIterable<LlmChunk> }`；`LlmRequest { messages, tools?, maxTokens?, signal? }`；`LlmChunk { kind:"text"|"reasoning"|"tool_call"|"usage"|"done"; ... }`；`MockLlmClient`（脚本化回复队列，供测试）。
- **tool_loop.ts**（框架核心）：`interface ToolExecutor { invoke(toolCall): Promise<ToolResult> }`（把权限判定/工具执行留在外面，loop 只管编排）；`runToolLoop(opts): Promise<ToolLoopOutcome>`，opts 含 `llm, tools(toolSchemas), executeTool, limits, budget, sink, heartbeatMs, steers, signal, noProgressRounds`。必须实现：轮次循环、四闸检查（每轮开始 `budgetReason` → 命中即收束并附「已收集信息」文案）、**心跳**（工具执行期间定时 `sink(heartbeat)`，静默超时 `LOOP_HEALTH.silentTimeoutMs` → 中止并报「安全模式触发条件」）、steer 注入（轮次边界）、`noProgressRounds` 死循环检测、usage 累计、abort 支持。产出 `ToolLoopOutcome { status:"done"|"budget"|"aborted"|"silent"|"no-progress"|"error"; reason: string; finalText: string; usage: BudgetUsage }`。

### 4.2 platform 适配层（S4）——唯一允许接触 Node API 的边界

`src/platform/types.ts`：

```ts
export interface FsAdapter { readFileUtf8(p: string): Promise<string>; writeFileUtf8(p: string, data: string): Promise<void>; readDir(p: string): Promise<string[]>; stat(p: string): Promise<{ size: number; mtimeMs: number }>; exists(p: string): Promise<boolean>; resolve(p: string): string; isInside(root: string, p: string): boolean; }
export interface ProcessResult { code: number | null; stdout: string; stderr: string; timedOut: boolean; }
export interface ProcessAdapter { run(cmd: string, args: string[], opts: { cwd?: string; timeoutMs?: number; maxBytes?: number }): Promise<ProcessResult>; }
export interface SqliteAdapter { open(path: string): Promise<SqliteDb>; }
export interface SqliteDb { all<T = unknown>(sql: string, params?: unknown[]): Promise<T[]>; run(sql: string, params?: unknown[]): Promise<{ changes: number }>; close(): Promise<void>; }
export interface NetAdapter { fetchText(url: string, opts: { timeoutMs?: number; maxChars?: number; headers?: Record<string,string>; maxRedirects?: number }): Promise<{ status: number; finalUrl: string; text: string }>; resolveIps(host: string): Promise<string[]>; }
export interface EmbedAdapter { embed(texts: string[]): Promise<number[][]>; }
export interface LoopsoarPlatform { fs: FsAdapter; process: ProcessAdapter; sqlite: SqliteAdapter; net: NetAdapter; embed: EmbedAdapter; }
```

- `src/platform/node.ts`：node 实现（fs/promises、child_process.execFile 带 timeout/maxBytes 截断、dns.lookup、net.fetchText 用全局 fetch 手写重定向计数）；**sqlite node 实现返回拒绝错误**（`LoopsoarNotImplementedError("sqlite 于 P4 引入 better-sqlite3 后实现")`）；embed node 实现：HTTP POST `http://127.0.0.1:8999/v1/embeddings`（可配置 baseUrl），连接失败抛错并注明「llama-server 未运行」。
- `src/platform/web.ts`：web stub——fs/process/sqlite 抛 `LoopsoarNotImplementedError("web 实现将在移动端阶段提供")`；net.resolveIps 抛错；embed 抛错。**web stub 只是占位，接口不变。**
- `src/platform/index.ts`：导出 `createNodePlatform(opts?): LoopsoarPlatform`、`createWebPlatformStub(): LoopsoarPlatform`、`LoopsoarNotImplementedError`。
- `src/platform/errors.ts`：`class LoopsoarNotImplementedError extends Error`。

### 4.3 工具与安全（S4）

- `tools/registry.ts`：`ToolPermissions { read?; write?; terminal?; network? }`；`interface ToolDefinition { name; description; permissions; schema: ZodTypeAny; execute(ctx): Promise<ToolResult> }`；`ToolContext { agentId; sessionId; platform; params: unknown; signal? }`；`ToolResult { ok: boolean; content: string; error?: string }`；`class ToolRegistry`：`register(def, opts?:{force?:boolean})`（同名拒绝除非 force）、`get(name)`、`list()`、`toolSchemas(toolsOnly?: string[])`（OpenAI function 格式）。
- `tools/builtin.ts`：`registerBuiltinMinimal(registry, platform)`——先注册 `file_read`（走 platform.fs，分页 offset/limit，返回带 `[错误]` 前缀的失败语义）；其余内置工具后续阶段补。
- `tools/hard_rules.ts`：`DANGEROUS_COMMAND_RE`（rm -rf /、dd、mkfs、curl|bash、chmod -R、fork bomb、全局包安装 npm i -g 等 10 条，注释来源 slime）；`hardRuleCheck(cmd: string): { blocked: boolean; reason?: string }`；`targetFromArgs(args: string[]): string | null`（提取路径目标）。
- `tools/policy.ts`：`classifyToolCall(tool, target, switchState): "auto"|"confirm"|"block"` + `explainDenial(...)` 给可执行建议。
- `tools/classifier.ts`：`SENSITIVE_FILES`/`PROTECTED_SOURCE_DIRS` 从 contracts 引入；`classifyCommand(cmd)`（只读白名单/确认/阻断三级占位实现）。
- `sandbox.ts`（安全核心，必须可测）：`type SandboxLevel = 0|1|2|3|4|5`；`DEFAULT_LEVEL_POLICY: Record<SandboxLevel, "auto"|"confirm"|"deny">`（L0/L1 auto、L2/L3/L4 confirm、L5 deny）；`interface SandboxDecision { action: "allow"|"confirm"|"deny"; level; reason }`；`class SandboxManager`：`checkPermission(req: { agentId; toolName; target?: string; kind: "read"|"write"|"terminal"|"network" }): SandboxDecision`——**八步决策链**：白名单目录命中→放行；目标越出工作目录（未授权）→拒绝；异常检测（写频率>100/min 用 60s 窗口实现、危险命令正则、循环>1000）→拒；deny_levels/deny_tools→拒；require_approval_tools→confirm；auto_approve→allow；require_approval_levels→confirm；兜底→deny（fail-closed）。`approveToolForSession(agentId, toolName)` 会话白名单。工具表为空的语义：`checkPermission` 对未知工具名 → **deny 而非抛错**；对「注册表尚未装配」与「工具不存在」在 `ToolRegistry` 层区分（`get` 返回 undefined 时调用方按「判不了≠不存在」处理）。
- `websearch/index.ts`：`safeFetch(url, opts, platform)`：协议白名单（http/https）→ DNS 解析 → **IP 与 PRIVATE_NET_RANGES 比对**（命中即拒）→ fetch（maxRedirects 5，逐跳重查 SSRF）→ 返回 {status, finalUrl, text}；`ssrfCheckIp(ip)` 纯函数可测。
- `audit.ts`：`class AuditLog`：`append(entry)`（串行队列）、条目 `{ts, agentId, action, target, level, status, reason}`；`AuditEntry` 类型。

## 5. services 包（S5）

- `packages/services/package.json`：`loopsoar-services`，依赖 `loopsoar-core`、`loopsoar-contracts`、zod。
- `src/events.ts`：`StreamChunkBatcher`（40ms / 24000 字合批）。
- `src/chat.ts`：`class ChatService`：`stream(input: { message; sessionId?; agent; platform; llm; registry; sandbox }, sink): Promise<ChatStreamResult>`——编排：`buildSystemSegments` → `ModelRouter` → `runToolLoop`（ToolExecutor 内部做权限判定：`sandbox.checkPermission` → allow 直接执行、confirm/deny 走 `PermRequestBus` 挂起 300s 超时按拒绝结算）→ 声称核验（每轮，`auditClaims`）→ 事件流归一（chunk/reasoning/tool/progress/done/error/heartbeat）。`PermRequestBus`：`request(decision)` → `{ choice, customReason }`，无 UI 时超时按 deny。
- `src/engine.ts`：`class LoopsoarEngine`：装配 `systemPromptFor(agent)`（身份铁律+能力自述占位）、`toolSchemas(toolsOnly)`、把以上接进 ChatService；`buildMindSegments()` 返回空 volatile 占位（P8 接入）。
- `src/gateway.ts`（services 内小文件）：把 ChatService 包装成 OpenAI 兼容的 `/v1/chat/completions` 请求/响应形状转换函数（gateway 包调用）。
- 测试思路（先写在源码注释，实际用例由 S8 补）：mock llm + 内存 fs。
