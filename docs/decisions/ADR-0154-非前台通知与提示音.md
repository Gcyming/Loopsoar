# ADR-0154 非前台系统通知与提示音

## 状态
已实现（v0.0.2 后续）。

## 背景
Agent 长任务、定时任务和 ask_user 询问都会让输出停下来，但用户切到其他窗口后看不到 Loopsoar 的状态变化。设置页需要一组通用开关，且提示音设计尚未定稿，先用系统默认音。

## 决策
- 仅当 Loopsoar **不在前台**（没有 BrowserWindow 处于 focused）时打扰用户；主窗口、Agent 小窗、托盘隐藏都按同一规则判断。
- 触发三类事件：
  1. 回合正常完成（`status === "done"`）；
  2. 异常中断（`error` / `silent` / `no-progress` / `budget`，以及 stream reject 的 `chat:stream:error`）；
  3. ask_user 询问（`ask:user`）。
- 用户主动停止（`aborted`）不通知。
- 设置·通用新增两个偏好，默认开启：
  - `notificationsEnabled`：系统通知；
  - `notificationSoundEnabled`：系统默认提示音。
- 通知与提示音相互独立：通知开启 + 提示音开启时由系统通知播放默认音（不额外 beep）；仅提示音开启时退回 `shell.beep()`；两者都关时不打扰。
- 通知点击恢复/聚焦主窗口，方便直接处理询问或查看结果。
- 定时任务原有的收尾通知改走同一通知器，并按 sessionId 与 ChatService 回合通知做 5 秒去重，避免同一次运行弹两条。
- 自定义提示音不在本 ADR 范围内，后续设计定稿后替换 `beepSystemSound`。

## 实现位置
- `packages/shell/src/main/notifications.ts`：前台判断、通知/提示音决策、去重、点击聚焦。
- `packages/shell/src/main/desktopNotify.ts`：Electron Notification 薄封装与系统默认 beep。
- `packages/shell/src/main/index.ts`：onTurnComplete、chat:stream:error、askBus 旁路与定时任务注入。
- `packages/shell/src/main/coreServices.ts`：`onAskUser` 旁路。
- `packages/contracts/src/validators.ts`、`packages/core/src/preferences.ts`：偏好字段与默认值。
- `packages/ui/src/SettingsGeneralExtras.tsx`、`SettingsNav.tsx`、`i18nSettings.ts`：设置开关与搜索入口。

## 后果
- 后台任务完成/失败、Agent 等待选择时用户能及时看到；不会在前台重复打扰。
- 提示音依赖系统通知/系统蜂鸣策略，部分系统静音时可能无声；这是“先用系统默认音”的预期限制。
- 同一会话的完成通知最多 5 秒一次，牺牲极端情况下连续两次独立完成的第二条通知，换取定时任务不重复提醒。
