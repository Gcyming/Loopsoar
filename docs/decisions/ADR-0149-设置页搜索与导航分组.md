# ADR-0149 设置页分区搜索与导航分组

- 日期：2026-11-28
- 状态：✅ 已验证（UI typecheck；组合根行数守卫：Settings.tsx 1396 / 上限 1396）
- 关联：`packages/ui/src/SettingsNav.tsx`、`packages/ui/src/settingsSections.ts`、`packages/ui/src/settingsUi.tsx`（Field.anchor）、`docs/decisions/ADR-0148`

## 背景

设置项随着 Loop/记忆/扩展/MCP/定时任务增加，侧栏变成了「按历史追加」：

- 通用、搜索引擎、外观、权限被塞进「基础」，供应商/规则/Loop/定时/技能/记忆/扩展/浏览器扩展/MCP 全在「能力」下 —— 相近功能没有相邻，宽泛功能被埋在中间；
- 用户找「压缩阈值」「图片输入」这类开关只能逐个分区翻，没有搜索。

## 决策

### 1. 导航按「宽泛优先、相近相邻」重排

固定五个组，组内按覆盖范围从大到小：

1. **基础**：通用 → 外观 → 搜索引擎 → 权限；
2. **模型与 Agent**：供应商 → 规则 → Loop → 技能 → 记忆；
3. **连接与扩展**：MCP → 扩展 → 浏览器扩展；
4. **数据与运行**：定时任务 → 终端环境 → 存储；
5. **其他**：高级 → 关于。

「通用」永远第一：它包含语言、启动、动画、压缩阈值等最宽泛的偏好。

### 2. 顶部分区搜索（带下拉结果）

- 索引 = 全部分区（label + hint）+ 高频字段条目（带 `anchor`）。
- 归一化：小写、去空白/中英标点，支持中英混输；多词查询按「全部词命中」处理。
- 排序：字段/分区名精确 > 前缀 > 包含 > 同义词 > 提示文案 > 分区名；同分按名称长度。
- 下拉最多 8 条，行内显示「名称 + 所属分区 · 提示」，↑↓ 选择、Enter 定位、Esc 清空。
- 只索引高频字段而不做全量表单索引：全量索引需要给每个 Field 起锚点并随表单改动维护，
  收益递减；未命中字段时仍能落到分区级。

### 3. 字段级定位

`Field` 新增可选 `anchor` → 渲染 `id="settings-anchor-<anchor>"`；选中结果后切分区、
`scrollIntoView({ block: "center" })`，并加 1.5s 高亮（动效关闭时改为 outline，避免闪动）。
已覆盖「通用」的语言、动效、窗口布局、广告拦截、图片输入、压缩阈值、恢复会话、关闭行为、轮次上限。

## 后果

- 侧栏导航从 Settings.tsx 抽出到 `SettingsNav.tsx`，Settings.tsx 从 1422 行降到 1396 行（组合根守卫上限同步下调）。
- 「基础/能力」旧分组键只剩模板匹配，词典里的 `settings.nav.group.capability` 已移除；新增 `agent` / `integrations`。
- 搜索结果浮层要求 nav 的 `overflow: visible`（否则会被裁成 190px）；滚动改由内层 `navList` 承担。
