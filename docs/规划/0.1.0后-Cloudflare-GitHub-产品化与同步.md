# 0.1.0 之后：Cloudflare + GitHub 产品化与同步（已记录，未开始）

> **状态：📝 已立项记录，暂不实施。**
> **触发条件：Loopsoar 0.1.0（可安装、可正常使用的首个发布版）完成后启动。**

## 1. 已确认的资产

- Cloudflare **免费计划**账号（可升级 Paid，但目前不需要）
- GitHub 账号（可建仓库、Actions、Releases、OAuth App）
- 多个域名，其中 **`loopsoar.com`** 为主域

## 2. 结论（当时查证）

| 需求 | 免费 Cloudflare 能否做 | 说明 |
|---|---|---|
| 官网/文档/下载页 | ✅ | Cloudflare Pages 静态站；GitHub 自动部署 |
| 安装包分发 | ✅ | GitHub Releases；R2 做镜像（10GB 免费、出网免费） |
| 跨设备同步左侧页面（URL/标签） | ✅ | Workers + D1 + GitHub OAuth + 客户端加密 |
| 跨设备同步聊天记录 | ✅（可选） | 体积/隐私更大，需单独授权 |
| Windows 安装包自动构建 | ✅ | GitHub Actions；私有仓注意 Windows runner 分钟数倍率 |
| 云端跑 worktree/测试/构建 | ❌ Free 不可用 | Cloudflare Sandboxes/Containers 仅 Workers Paid（$5/月起） |
| 自动发邮件/验证码 | ❌ Free 不可用 | Email Routing 只免费转发；Email Sending 需 Workers Paid |
| 代码签名 | ❌ 与 Cloudflare 无关 | Windows 代码签名证书约 $200–500/年，用于减少 SmartScreen 警告 |

付费不是页面持久化的前提：**本地页面持久化已实现**；云端同步是“跨设备备份”，免费可做；付费只卡“云端执行器”。

## 3. 分阶段计划

### P0：官网 + 下载 + 更新检查（预计 1–2 个工作日，免费）

- [ ] `loopsoar.com` NS 接入 Cloudflare；`www` 301 → apex
- [ ] Cloudflare Pages 项目接 GitHub 仓库，自动部署
- [ ] 官网：产品介绍、截图、系统要求、下载按钮、更新日志
- [ ] 文档站 `docs.loopsoar.com`（VitePress/Astro 均可）
- [ ] 安装包发布到 GitHub Releases；`dl.loopsoar.com` 用 R2 做镜像/旧版归档
- [ ] `api.loopsoar.com/version` 更新检查 JSON（Workers 静态路由或 Pages Function）
- [ ] `support@loopsoar.com` Email Routing 转发
- [ ] 反馈/内测申请表 + Turnstile；Web Analytics
- [ ] `admin.loopsoar.com`/预览站用 Cloudflare Access 保护
- [ ] GitHub Actions：tag 触发 Windows 打包 → Release 资产 + checksums + 更新 feed

**验收**：陌生用户打开 `loopsoar.com`，能下载、看文档、提交反馈；更新检查可用；全链路 0 服务器、0 Cloudflare 费用。

### P1：跨设备页面同步（免费，0.1.0 发布后视需求启动）

- [ ] Worker `api.loopsoar.com`：GitHub OAuth Device Flow 登录（桌面端不存 client secret）
- [ ] D1 表：`users` / `devices` / `session_snapshots`（密文、version、device_id、updated_at）
- [ ] 客户端：只在退出/切会话/手动触发时上传；启动/手动拉取
- [ ] 同步内容只限现有 `SessionStore.browser`：tabs(url/title/history/activeIndex)；**不上传 Cookie/页面正文/表单**
- [ ] 客户端 AES-GCM 加密后再上传；密钥来自用户口令或系统钥匙串；服务端不可读
- [ ] 冲突：version + 409，提示“本机/云端”，默认不静默覆盖；不做实时双向
- [ ] 设置页“云同步”分区（登录/退出/立即同步/只同步标签或含聊天）
- [ ] 配额监控：Workers 100k/天、D1 5M 读/100k 写/天、5GB；超额给出可读提示

**验收**：A 电脑关闭前打开会话 S 的页面；B 电脑登录同一账号后打开 S，左侧恢复同一组 URL/活动标签；断网/退出登录时本地功能不受影响。

### P2：云端 worktree / 远程执行（仅在确有需求时，付费）

- [ ] 评估 Workers Paid（$5/月） + Cloudflare Sandboxes/Containers
- [ ] 远端仓库前提：GitHub 私有仓 token 或可访问远端；本地独有提交需先 push/打包
- [ ] 排除敏感文件；用户显式授权上传
- [ ] 先做 POC：在 Sandbox 内 clone → `git worktree` → 跑一条测试 → 回传日志，不接主流程
- [ ] 代码签名证书采购（与 Cloudflare 无关，但发版必需评估）

**验收**：不改变本地方案可用性；云端只是可选执行器。

## 4. 目标架构（P0/P1）

```
loopsoar.com                  Pages（官网/下载/文档/更新日志）
www → 301
docs.loopsoar.com             Pages（文档）
dl.loopsoar.com               R2 自定义域（安装包镜像）
api.loopsoar.com              Worker（鉴权/同步/版本/反馈）
admin.loopsoar.com            Worker/Pages + Cloudflare Access

Loopsoar 桌面端
  └─ 本地 SessionStore（已有 browser 快照）
       └─ 可选：sync 模块（加密→HTTPS→Worker）+ GitHub Device Flow
```

约束：
- Cloudflare 代码放独立目录（如 `cloud/`），不反向依赖 `packages/ui`/`shell`；不把 Electron 代码打进 Worker。
- 同步 API 版本化（`/v1/...`）；D1 schema 有迁移脚本；secrets 只用 Worker secrets，不进仓库。
- 客户端加密在本地完成；服务端只存密文和版本号。
- 新增 IPC 仍走 `contracts → gen → core/shell → ui`；不允许 UI 直接 fetch 云 API（若需要，经 shell 受信通道）。
- 不修改现有本地持久化语义；云同步失败不得影响本地启动/对话/浏览。

## 5. 需要用户完成/授权的动作（启动时再执行）

1. Cloudflare 登录与邮箱验证；`loopsoar.com` NS 接入 Cloudflare（免费）
2. Cloudflare API Token 或本地 `wrangler login`（**不要发到聊天**；用本机环境变量/交互登录）
3. GitHub 建远端仓库；授权 Cloudflare Pages/Workers 读取；创建 OAuth App（Device Flow）
4. 可选 P2：开通 Workers Paid、绑定支付方式；GitHub 私有仓 token
5. 可选：Windows 代码签名证书

## 6. 明确不做/不建议

- ❌ 用 Pages 承载 >25MiB 的安装包（应走 Releases/R2）
- ❌ 用 GitHub 仓库/Gist 当高频数据库（限流 + 每次 commit + 无并发）
- ❌ 免费 Workers 跑长时间/重 CPU 任务
- ❌ 把 Cookie、页面正文、API Key 上传云端
- ❌ 多个域名做重复站点（只保留主域 + 必要镜像，其余 301）
- ❌ 把云同步作为本地功能的前置依赖

## 7. 免费额度参考（2026-11 查证）

- Workers Free：100k 请求/天、10ms CPU/请求（[limits](https://developers.cloudflare.com/workers/platform/limits/)）
- D1 Free：5GB 存储、5M 行读/天、100k 行写/天（[pricing](https://developers.cloudflare.com/d1/platform/pricing/)）
- R2 Free：10GB 存储、1M Class A、10M Class B/月、出网免费（[pricing](https://developers.cloudflare.com/r2/pricing/)）
- Pages Functions 请求计入 Workers Free；静态请求免费（[pricing](https://developers.cloudflare.com/pages/functions/pricing/)）
- Email Routing 转发免费；Email Sending 需 Workers Paid（[Email Service](https://developers.cloudflare.com/email-service/)）
- Containers/Sandboxes：Free N/A，Workers Paid $5/月（[pricing](https://developers.cloudflare.com/containers/platform/pricing/)）
- GitHub Actions：公开仓免费不限；私有仓 Free 约 2,000 分钟/月；Releases 免费（[billing](https://docs.github.com/en/billing/managing-billing-for-github-actions/about-billing-for-github-actions)）

## 8. 启动时先确认的问题

1. 官网先做中文还是中英双语？
2. 是否开源/公开仓库（影响 Actions 免费额度与信任）？
3. 云同步是否默认开启，还是仅手动登录后开启？
4. 同步范围：只标签/URL，还是也聊天记录？
5. 用户加密口令方案（忘记口令不可恢复）是否接受？
6. 是否要国内下载镜像/备案（Loopsoar 用户主要在哪个网络环境）？
