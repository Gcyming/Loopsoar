# Loopsoar 0.0.1 内测发布说明

> **内测构建，未公开发布。** 0.0.x 均按内测处理，不构成稳定版承诺。
> 发布通道：GitHub Releases（手动下载安装；自动更新入口已内置，正式启用需签名版）。

- 版本：0.0.1
- 平台：Windows 10/11 x64（NSIS 安装包 + 免安装 zip）
- 构建：Node 24 / Electron 45.0.0 / Chromium 依 Electron 版本
- 代码签名：无（Windows 会提示「未知发布者」，属预期）

## 1. 安装包

| 文件 | 用途 |
|---|---|
| Loopsoar-Setup-0.0.1.exe | NSIS 安装包，按用户安装（无需管理员），可选安装目录 |
| Loopsoar-0.0.1-win-x64.zip | 免安装版，解压后运行 Loopsoar.exe |
| SHA256SUMS.txt | 安装包校验值（sha256sum -c 或 PowerShell Get-FileHash 对照） |
| latest.yml / *.blockmap | 自动更新元数据（随 Release 一起上传，供后续版本使用） |

安装/解压后首次启动会创建数据目录 %APPDATA%\loopsoar。卸载默认保留该目录（见第 6 节）。

安装向导在「选择安装位置」之后新增**安装选项**页：
- 创建桌面快捷方式（默认勾选）；
- 开机自动启动 Loopsoar（默认不勾选，写入当前用户 Run 项，卸载时自动清理）。

卸载向导新增数据处理选择：默认**保留**用户数据；勾选「删除用户数据」才会清理
%APPDATA%\loopsoar 与 %LOCALAPPDATA%\loopsoar（不可恢复）。

## 2. 本版包含

- **浏览器优先的 Agent**：内置标签页与地址栏，Agent 可导航、读取页面、点击/输入、截图、
  保存页面；书签、历史、下载与广告拦截在同一外壳内。
- **对话与工具循环**：多会话、流式输出、工具调用与确认、计划模式、子代理、附件
  （图片 / PDF / Office / 文本）、上下文压缩。
- **记忆**：Markdown 记忆库（Obsidian 可直接打开）、内容哈希索引、外部编辑热同步、
  回顾命名与合并建议、记忆图谱。
- **规则**：全局 / 项目规则（AGENTS.md）、路径与命令守卫、候选审核、规则体检、历史回滚。
- **扩展与技能**：本地扩展以独立子进程隔离运行（Node 权限模型），技能目录、MCP Server 接入。
- **Loop**：内置 loop 与自定义脚本 loop（独立子进程 + 超时/回退）。
- **定时任务与托盘**：按 cron 触发会话；「最小化到托盘」后定时任务继续运行。
- **终端与后台任务**：持久终端会话、后台命令进程树管理。
- **工作区 / worktree**：按项目隔离会话与规则，Git worktree 隔离改动。
- **文档**：PDF 文本抽取（含标准字体）、Office 文档读取与转换。
- **设置**：供应商（OpenAI / Anthropic 兼容）、模型列表、语言、主题、诊断与关于。
- **数据与诊断**：设置 → 关于可打开数据目录、导出数据备份、导出诊断包（日志/版本/审计，不含密钥与会话正文）。
- **本地崩溃转储**：crashReporter 只写本地 minidump（默认不上传），随诊断包导出。

## 2.1 本版修复（发布前回归）

- **首次安装双击没反应**：userData 目录不存在时 Chromium 单实例锁会失败，旧逻辑把它当成「已有实例」直接退出。
  现在启动先创建数据目录，并用 PID 锁兜底；只有确认另一个实例存活才退出。
- **安装器许可页中文乱码**：LICENSE 改为 UTF-16LE + BOM 后再交给 NSIS。
- **「调试」按钮无效 / 面板被网页盖住**：修复无 sessionId 时的标签解析（回落到用户可见标签），
  并把调试面板视图提到最上层。
- **记忆向量后端**：设置 → 通用新增「记忆向量后端」（Flat / SQLite-vec），随包原生模块从
  `resources/native` 加载，失败自动回退 Flat。
- **崩溃转储位置**：crashReporter 在 userData 落位之后启动，minidump 落在
  `<数据目录>\Crashpad\reports\*.dmp`，诊断页显示该路径。

## 3. 数据、备份与回滚

- 数据目录：%APPDATA%\loopsoar（设置 → 关于/诊断 可查看完整路径）。
- **升级前自动备份**：启动时若发现版本号变化，会把用户数据复制到
  %APPDATA%\loopsoar\backups\pre-<旧版本>-<时间戳>\（排除浏览器缓存、日志、traces；
  单文件超过 64MB 跳过）。
- 手动备份：设置 → 关于 →「导出数据备份」，或关闭应用后复制整个数据目录。
- 回滚：卸载当前版本 → 安装旧版本 → 如需还原数据，把对应 backups 目录内容覆盖回数据目录。
  （0.0.1→0.0.2→0.0.1 的完整演练记录见 docs/releases/UPGRADE-DRILL.md。）

## 4. 已知问题

1. **未签名**：SmartScreen 会拦截，需「更多信息 → 仍要运行」。
2. **自动更新尚未正式启用**：入口与 latest.yml 已就绪，但本版未签名，先手动覆盖安装；
   覆盖安装不会删除数据，更新前也会自动备份。
3. **可选向量后端随包但默认不启用**：better-sqlite3 / sqlite-vec 已随包（安装目录 resources 内），
   默认仍是 flat 后端；设置 → 通用 →「记忆向量后端」可切换为 SQLite-vec（重启后生效，失败自动回退 flat）。
4. **干净机器验收范围**：本版在 Windows 11 x64、非管理员账户、中文安装路径完成验证；
   Windows 10 x64 与「安装路径含空格」尚未实机验证，若有问题请反馈。
5. **代码签名 / 更新包签名校验 / 灰度**按发布计划留到 0.1.0 前的阶段 3。
6. 测试期间若出现启动失败，请提供 %APPDATA%\loopsoar\crash.log 的最后若干行。
