# Loopsoar 内测告知 / 测试者须知

欢迎参与 Loopsoar 0.0.x 内测。开始之前请确认以下事项：

1. **这是内测版**：功能与数据格式都可能变化，可能崩溃或丢数据，不要用于生产。
2. **不要用真实敏感数据**：真实 API Key 之外的密钥、身份证件、客户资料、未公开代码都不要输入。
3. **模型请求会离开本机**：对话、页面内容、附件文本会发送到你配置的模型供应商。
4. **崩溃日志在本地**：%APPDATA%\loopsoar\crash.log，应用不会自动上传；反馈时自行决定是否提供。
5. **安装包未签名**：Windows 会提示未知发布者；只从官方 Release 下载并核对 SHA256SUMS.txt。
6. **无自动更新**：新版本手动下载覆盖安装；升级前应用会自动备份数据目录。
7. **卸载保留数据**：程序目录被删除，%APPDATA%\loopsoar 保留；需要彻底清理请手动删除。
8. **反馈渠道**：GitHub Issues；请附版本号、系统版本、复现步骤与 crash.log 片段。

继续安装即表示你已知悉以上内容，并同意 LICENSE 中的内测许可条款。
