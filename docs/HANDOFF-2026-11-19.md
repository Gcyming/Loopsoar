## 2. 本会话已完成

### 2.1 权限、安全与扩展生命周期

- 扩展声明的工具权限必须是指纹清单权限的**子集**；越界 fail-closed 并记录冲突。
- 扩展调用超时即 `failRun`（注销 + kill）；崩溃按 1s / 5s / 15s 退避，最多 3 次，5 分钟窗口内重启。
- `canUseTool` 进入真实 chat 执行链；扩展权限与内置工具权限使用同一套判定。
- 敏感路径 / 受保护源码目录接入 `file_write` 前置判定；直接写 `.env`、`.git/config` 等会被拒绝。
- 关键文件：`packages/shell/src/main/extensionRuntime.ts`、`packages/shell/src/main/fileTools.ts`、`packages/core/src/tools/classifier.ts`、`packages/services/src/chat.ts`。

### 2.2 Loop 回退、看门狗与取消

- 已执行工具的失败**不再回退重放**，直接安全停止并如实报错；只有“尚未执行”的工具才允许回退 builtin。
- 看门狗改为进展/心跳驱动；超时先 abort，再等待 runner 收尾，不与 builtin 并发。
- 关键文件：`packages/core/src/tool_loop.ts`。

### 2.3 Anthropic thinking / max_tokens

- `reasoning` 与 `reasoningSignature` 全链路回灌（`LlmMessage` → `toAnthropicMessages` → tool loop）。
- `max_tokens` 由模型能力推导；thinking budget 夹到 `maxTokens − 1024`。
- 关键文件：`packages/core/src/llm/anthropic.ts`、`packages/core/src/llm/index.ts`、`packages/core/src/tool_loop.ts`。

### 2.4 输出过滤

- URL、行内代码、围栏代码为保护区间，只在普通文本区间做敏感信息/规则替换。
- 流式过滤为**行级状态机**，维护 fence 状态，避免跨 chunk 误伤。
- 关键文件：`packages/core/src/filter.ts`；测试 `tests/core/filter.spec.ts`。

### 2.5 记忆

- 五闸合并：tags 只分类、不否决；合并时 tags 取并集；跨 agent 绝不合并。
